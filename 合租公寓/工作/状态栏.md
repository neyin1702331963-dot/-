# 合租公寓 · 状态栏设计（KV V4.0 轻量方案）

## 选型
- 方案：KV V4.0（statusbar.md 三段正则模板）
- 理由：3 位固定室友、字段固定、日常暧昧非长线战斗 → 极简面板首选；雷达法引擎超 10000 字符限制且复杂度过高，本卡无需嗅探/液态快照护城河。
- 三段正则原样复用 statusbar.md 的 replaceString，不改一字（findRegex：`<status>` / `<!-- Z_CONTENT -->` / `<!-- Z_SCRIPT -->`）。

## 字段映射（合租公寓主题）
| 模板字段 | 本卡用途 | 示例 |
|---|---|---|
| data-env `tm` | 时间（含星期/时段） | `周五 19:30` |
| data-env `loc` | 当前地点 | `合租公寓·客厅` |
| data-env `goal` | 当前情境一句话 | `搬家第一晚，三人凑齐` |
| data-env `rd` | 现场记录 | `冰箱第四格还空着` |
| data-env `chars` | 在场室友 | `林夏,顾沉,沈知意` |
| data-st `zy` | 三人好感度条（进度条） | `林夏好感:30/100,顾沉好感:10/100,沈知意好感:25/100` |
| data-st `npcs` | 三人当前状态卡（位置·活动 + 好感数） | `林夏\|客厅·递饮料\|30,顾沉\|门口·围观\|10,沈知意\|厨房·切水果\|25` |
| data-opt `c1-c4` | 4 个行动选项 | `c1="帮林夏搬箱子\|拉近距离\|low\|safe"` |

> 标签页"线索"复用为"近况"无妨；本卡主要看场景 + 好感 + 选项。

## AI 输出协议（写进世界书条目，每轮末尾）
首条必须完整（继承基准）；后续仅输出变化字段，data-opt 每轮必给。
好感度规则：日常互动 +1~3；正中对方点 +3~5；越界/踩雷 -3~8；范围 0-100。
