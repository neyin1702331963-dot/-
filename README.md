# 魔女能力选择 · 粒子卡面（SillyTavern 正则注入）

SillyTavern 风格的"楼层 HTML 注入"正则脚本：开场让玩家从一组魔女能力中选择，
卡面用纯 Canvas 2D 模拟伪 3D 粒子点云。本次为**重构 v2**。

## 本次改了什么

针对原版三个问题，对应三项改造（造型方向 / 切换 / 体积，均由使用者拍板）：

| 原问题 | v2 方案 |
|--------|---------|
| **太抽象、辨识度低**（13 个造型都是线弧堆叠，王冠/镜/钟分不清） | 改成**正面发光线描符号**：每个能力一个清晰正面图标，粒子勾出轮廓 + 微 3D 厚度 + 轻浮动，不再自由翻滚 |
| **切换太生硬**（`go()` 瞬间重建点云） | **粒子形变补间**：上一造型的粒子平滑流动、重组成下一造型（缓动 `easeInOutCubic`，约 640ms） |
| **单条正则 replaceString 上限 2w 字符** | 只重写 JS 段；引擎全程**单引号**以塞进 `onerror="..."`；每段实测均 < 20000 |

当前为**模板验收版**：先做 3 个差异最大的能力（**星门启录→钥匙**、**晶钟裁时→时钟**、
**假面授冠→王冠**）验证观感，确认后再套用到全部 13 个。

## 文件

| 文件 | 说明 |
|------|------|
| `魔女能力选择-v2.json` | **成品**。直接导入 SillyTavern 正则即可（三段：主骨架 / CSS / JS） |
| `preview.html` | 浏览器预览页，复刻了 SillyTavern 的占位符替换链，导入前可先看效果 |
| `src/engine.js` | 新 JS 引擎源码（粒子池 + 形变补间 + 正面渲染 + 造型库 + 输入框对接） |
| `src/original.json` | 原始 v1 脚本，构建输入 / 对照参照 |
| `src/build.js` | 构建脚本：把引擎装回 JSON、生成预览页、核对每段字符数 |

## 构建 / 预览

```bash
node src/build.js          # 生成 魔女能力选择-v2.json 与 preview.html，并打印各段字符数
# 浏览器打开 preview.html 即可查看（拖拽卡面可微调视角，‹ › 切换能力，确定选择写入输入框）
```

## 引擎要点

- **造型库**：`bKey` / `bClock` / `bCrown` 各用线描图元（`seg`/`arc`/`ring`/`poly`/`star`/`dot`）
  把图标轮廓"撒"成粒子；`build()` 把任意点数归一到固定 `ICON=820`，保证逐帧一一对应可补间。
- **粒子池**：前 `ICON` 个是会形变的图标点，其后是跨能力**固定不变**的背景星尘（只让前景图标流动）。
- **正面渲染**：不再整体自转，只做小幅度摇摆（`sin/cos` 微调 rx/ry）+ 上下浮动，保证图标始终正对、可读；
  拖拽可临时倾斜，松手带阻尼回正。
- **2w 约束**：JS 注入在 `onerror` 双引号属性内，故引擎源码**不含任何双引号**。

## 扩展到 13 个能力

在 `src/engine.js` 里：

1. `A` 数组补齐其余 10 个能力的文案，末位字段填一个造型 key；
2. 在造型库新增对应 `bXxx(T)` 线描函数，并注册进 `SHAPES`；
3. `node src/build.js` 重新生成。若届时 JS 段逼近 2w，可把造型库拆成独立正则脚本，
   在引擎留 `[能力造型库]` 占位符由后续脚本填充（正则嵌套）。
